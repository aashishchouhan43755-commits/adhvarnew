# Adhvar Indoor Navigation System

Adhvar is a Flutter and FastAPI indoor-navigation project. The included demo
models the Adhvar Innovation Center with one building, three floors, thirty
rooms, lifts, staircases, washrooms, emergency exits, interactive SVG maps,
and Dijkstra-based multi-floor routing.

See [frontend/README.md](frontend/README.md) to run the Flutter app and
[backend/README.md](backend/README.md) to run the API and database setup.
